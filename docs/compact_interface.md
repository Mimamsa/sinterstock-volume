# 精簡視覺化介面

主視窗提供顯示內容控制、地面法線距離調整、PLY／Mesh 匯出及體積資訊。處理流程、柱體定案模型與倒凸邊界沿用啟動時的命令列設定；主畫面另提供原點到地面法線距離 d 的調整。

## 主畫面

1. **點雲檔案選單與匯出**：切換單份 PLY；匯出完整處理後實測與補點。
2. **左右各自的顯示內容**：原始點雲、處理後料面（實測＋補點）、清理後實測、補點、柱體量測證據，或不顯示點雲。兩側可獨立開關柱體框及地面／料堆邊界。左側另有「隱藏屋頂與構架」，依已校準的雙斜屋頂平面隱藏屋頂及其下方指定垂直深度內的點（預設 3 m，可於旁邊調整 0.1–15 m），方便觀看內部料堆。只影響繪圖，不重新處理、不影響體積或完整匯出；屋頂模型不可用時開關停用。
3. **共用著色**：單色／強度／Z 高度、上下限、自動 P5–P95、補點橘色，以及座標原點／軸顯示。
4. **體積報告**：柵格淨體積與實驗性 Mesh 試算、兩者差值、總淨體積、料堆數、柱體扣除量、柵格覆蓋／缺測、地平面、末段過濾的同地面體積差，以及每堆淨體積、面積、實測／補點支撐體積及內部缺測。

預設左側原始、右側處理後料面；柱體框預設關閉，地面／邊界預設在兩側都顯示，仍可各自關閉。兩側共用體積計算採用的地平面（自動估計或手動指定），以每 10 m 一線的網格呈現；須有有效地面分析結果才會顯示。選擇柱體量測證據只影響觀看，不把證據加入料堆或匯出。

兩側共用相機，左鍵旋轉、右鍵或 Shift 拖曳平移、滾輪縮放；雙擊重新取景。操作提示放在點雲區滑鼠提示，不再佔主畫面。處理中、錯誤與匯出完成訊息只短暫使用狀態區，不再列出整串處理診斷。

## 參數與審查

去雜點、結構清理、補洞、末段過濾及地面估計等設定仍可用原有命令列參數啟動，例如：

```bash
./build/pointcloud_compare --surface-outlier-tolerance 0.8
./build/pointcloud_compare --ground-plane 0,0,-24.74
./build/pointcloud_compare --help
```

柱體審核與編輯不再出現在主視窗。查看定案柱體時，可選擇「柱體量測證據」並打開「柱體框」，搭配[現行結構清單](columns_final.md)、[梁柱尺寸及檢查圖](structural_beams.md)、`config/column_semantics.json` 與 `config/column_catalog.json` 檢查。模型幾何與分群不因這次介面調整改變。

點雲、地面疊圖及著色等顯示開關不觸發重新處理、不改體積，也不複製 GPU 點資料；「調整原點到地面距離 d」須按套用按鈕，會重新處理並更新體積。匯出維持先前完整資料重算／輸出流程，與當下顯示何種內容無關；原檔及既有輸出仍不覆寫。

## 驗證範圍

已完成 C++／Qt5 編譯與 9 項 CTest；地面法線距離測試涵蓋 a、b 保持原擬合值、調整後體積、原擬合統計保留、距離換算、零距離、正負距離、參數衝突、非有限數值及缺少實測地面支撐。保留 `--smoke-test`，在可用桌面環境可檢查兩側所有顯示模式的 framebuffer。此輪未啟動桌面 GUI，尚未實機驗證實際版面與滑鼠互動。

屋頂／構架開關是顯示高度帶裁切，不是逐根構架語意辨識。增加深度可遮掉較低構架，但也可能遮住較高料面；調整到能看清料堆即可。

目前另提供「匯出料面 Mesh」按鈕與 mesh 體積比較；每堆明細仍為柵格結果。請參考[mesh 試算方法與匯出限制](mesh_volume_trial.md)。

## 固定擬合坡度、調整地面法線距離

首次自動地面分析成功後，距離欄位帶入原點到擬合平面的最短距離 `c / √(1+a²+b²)`；若啟動時有指定 `--ground-distance`，則顯示指定距離。

勾選「調整原點到地面距離 d」，輸入帶正負號的距離（公尺），再按「套用地面並重新計算」。a、b 固定使用清理後實測的擬合值，程式以 `c = d × √(1+a²+b²)` 依 d 正負號設定地面位置。實際最短距離為 `|d|`，d 為負表示地面在原點下方，為正表示在上方。此距離沿平面法線量測，與沿 Z 軸的高度差不同；d = 0 表示平面通過原點。取消勾選並套用可恢復完整擬合平面。

套用會重新執行處理流程，同步更新兩側地面、柵格、Mesh 與匯出所用結果；尚未套用的編輯不改結果。已套用距離會沿用到切換的檔案，各檔仍各自擬合 a、b。命令列範例為 `--ground-distance -24.31`，不能與 `--ground-plane` 同時使用；舊的 `--ground-constant` 已移除。

仍須有足夠實測地面支撐，不能用距離跳過擬合驗證。完整手動平面或地面分析失敗時，GUI 調整停用。報告保留原擬合 c，並顯示採用的法線距離；RMSE 與內點數描述原擬合品質，不代表調整後誤差。

## 拍照模式與擷取畫面

主畫面上方提供「拍照模式」與「擷取畫面」。勾選拍照模式後，兩側左上角的顯示內容／抽樣點數及結構說明文字、左下角的高程或強度色階（含上下限數值）會隱藏；取消勾選即可恢復。相機、點雲著色、地面、料堆與柱體標籤、座標軸維持目前設定，可用各自的開關調整。此模式只改繪圖，不重新處理或改變體積。

按「擷取畫面」會擷取當下左右並列的視覺化區域，包含中央分隔線，存成單張 PNG。影像依目前拍照模式及疊圖設定產生；需要乾淨角落時，先勾選拍照模式再擷取。存檔對話框可選路徑與檔名，預設為 `<點雲檔名>_comparison.png`；未輸入副檔名時補上 `.png`，既有檔案覆寫會要求確認。影像不包含控制列、體積表格與其他桌面視窗，解析度依視覺化區域大小及螢幕像素比例決定。

點雲載入／重新計算時及載入失敗後，擷取按鈕停用；OpenGL 未就緒或儲存失敗時會在狀態區顯示原因。取消存檔不寫入檔案。
