# 體積前的局部料面離群清理

在「重建料面／補洞」之後、「估計正式地平面與建立體積格」之前，新增末段過濾，預設啟用。清理同時作用於實測點及補點，右側視覺化與完整 PLY 匯出使用同一份清理結果；原始 PLY 不修改。

## 方法

1. 將完整清理後的實測點放入 0.5 m XY 支撐格，各格以高度中位點作等權支點。這只是離群值判斷模型，不以代表點替換原始量測。
2. 每格使用周圍 1.5 m 內的其他實測格，不讓本格或合成點自行支持自己；至少六個鄰格且有非退化的二維分布才擬合。
3. 以迭代穩健加權平面估計局部料面，利用 MAD 評估殘差尺度。鄰域殘差尺度超過 0.2 m、至少 75% 的鄰格不能一致支持平面，或擬合坡度超過 2 時跳過該格，避免對多層、尖銳邊界或不足支撐區強行平滑。
4. 原始點／補點偏離局部料面的絕對高度，大於 `max(設定門檻, 4 × 殘差尺度)` 時刪除。預設門檻為 **0.6 m**，高點與低點都檢查，並保留其他點的座標／強度。
5. 所有判斷使用同一份原始實測支點，一次性刪除，不反覆連鎖侵蝕。刪除後沒有再次補洞，缺乏支撐的格仍會維持未知，避免剛刪掉的雜點又被補回。

這是保守的局部幾何離群檢查，並不是語意判別的保證。面積很大的連續假表面、鄰域不足的孤立點，以及與料面相貼近的雜點仍可能保留；小範圍真實高低起伏也可能被誤刪，請用開關與門檻比較，尤其是裸露地坪或陡邊附近。

## 介面與命令列

精簡介面不再顯示過濾參數列；請以命令列取消過濾或修改門檻。門檻越小越嚴格，預設 0.6 m。

```bash
./build/pointcloud_compare
./build/pointcloud_compare --surface-outlier-tolerance 0.8
./build/pointcloud_compare --no-surface-filter
```

只有啟用建築結構處理時才執行末段清理；即使停用體積計算，仍會作用於右側及匯出。C++ 參數在 `StructureOptions.surfaceFilter`，可修改支撐格距與鄰域半徑。

狀態列與 `--check` 輸出會列出刪除的實測／補點數量。若成功估計地面，另顯示固定同一地面、柱體、邊界及門檻的前後淨體積差。正式地面先由過濾後實測估計；若有指定 `--ground-distance` 或套用 GUI 法線距離調整，則保留擬合 a、b，依原點到地面法線距離 d 換算 c，再作為正式地面。比較時暫時加入被刪點、固定此地面重算，之後恢復清理結果。因此這個差值衡量刪除點的影響，不混入兩次獨立地面估計的差異，也不等於關閉過濾後重新自動估地面的結果。

因為每格取最低高度，刪掉低離群點可能使體積增加；刪掉孤立高點或失去支撐的格可能使體積減少。此功能不以任何盤點體積作為擬合目標。

## 驗證

新增測試涵蓋：實測高／低離群點、補點離群、斜坡原樣保留、尖銳雙層邊緣保留、稀疏／共線鄰域跳過、關閉開關不修改點。保留點的 XYZ 與強度不做平滑或平均。另有完整流程原有的最低高度、場域凹邊界、柱體體積與匯出測試。
