# 保留柵格、另加料面 Mesh 體積試算

目前兩種方法同時計算，原本 **10 × 10 cm、每格最低離地高度** 的柵格結果與料堆表格保留。新增的是開放料面 TIN 對共同地平面的直接積分，不是閉合三維實體重建，也沒有將柵格體積轉成 mesh 數字。

## 共用與不同之處

兩種方法使用同一份校準、柱體／結構物清理、補洞及末段離群過濾後的完整實測／補點；共用柵格流程確定的地平面（自動擬合、保留擬合 a／b 並調整 c，或完整手動指定）、倒凸字型邊界、牆邊內縮、已確認柱體、0.2 m 高度門檻及最小區塊面積設定。顯示點數上限、左側隱藏屋頂與著色不影響任何結果。

Mesh 另做以下處理：

1. **建立唯一高度支點**：預設 0.25 m XY 支點格，各格優先使用實測的最低離地點，無實測才用補點。使用實際點的 XY／Z，不平均、不改寫原始資料。支點格只控制 TIN 密度，不是體積積分格。最多 250,000 個支點，超過回報錯誤，要求明確加大支點間距。
2. **XY Delaunay TIN**：每個 XY 位置只有一個料面，不會把重疊高度帶當成多份體積。最大 XY 邊長預設 2 m，並限制外接圓半徑與坡度，避免任意跨接大缺測區。這仍會內插部分小缺口，不能將 TIN 覆蓋直接視為全部實測覆蓋。
3. **幾何裁切**：場域先以幾何內縮處理（預設 0.4 m，轉角圓弧以分段線近似），每片三角形與實際凹輪廓求交，不將場域當成凸包或長方形。穿過高度門檻的三角形再裁切，計算的是完整離地高度，不減掉門檻值。
4. **直接積分**：料面與地坪在三角形內均為線性平面。以 `V = XY 投影面積 × 平均頂點離地高度`，或等價的多邊形面積矩積分計算，不作體積柵格取樣。
5. **結構聯集交集**：柱、梁、箱體使用與柵格共用的[三維聯集裁切](structural_union_volume.md)，只扣地面至料面之間的部分，保留梁下空間，重疊只扣一次。
6. **小區篩選**：有效三角形依共邊連通分群，按扣除穿透料面的柱截面後的投影面積排除小區。這是三角形連通分群，不是柵格八鄰接，因此區塊數及邊緣小區判斷可能不同；柱體切開單片三角形的多部分仍屬該三角面，不能當成嚴格的三維物件分割。

因此兩種結果有差異時，來源可能包含支點選取、三角內插覆蓋、門檻裁切、邊界面積與分群，不只是積分公式。柵格法只收整格位於場內者；mesh 可積分裁切後的部分邊界面。不能只因 mesh 與盤點量更近就判定更準。

## 介面與選項

體積摘要並列「柵格淨體積」、「Mesh 試算」、差值、mesh 柱體扣除量、TIN 覆蓋及三角形數。下方每堆明細仍是 **柵格料堆**；mesh 目前提供全場試算，沒有將三角形區塊硬配對為同一個柵格料堆 ID。

新增「匯出料面 Mesh」按鈕，匯出可用 CloudCompare／MeshLab 檢查的 PLY 三角面。一般「匯出處理後 PLY」仍是完整處理點雲。

```bash
# 預設同時計算柵格與 mesh
./build/pointcloud_compare
# 只保留原本柵格計算
./build/pointcloud_compare --no-mesh-volume
# 調整 mesh 支點密度與最大跨接邊長（不改體積柵格）
./build/pointcloud_compare --mesh-support-spacing 0.5 --mesh-max-edge 2
# CLI 完整比較報告
./build/pointcloud_compare --check
```

`--mesh-max-slope` 預設 3，單位為 dz／水平距離；`--no-volume` 會關閉兩種體積。當共同地面不可用時 mesh 比較亦不成立；其他 mesh 錯誤獨立顯示，不覆蓋已成功的柵格結果。

## 匯出 mesh 的意義

輸出為通過場域／高度／小區篩選的 **開放上表面**，包含供柱體相交積分的虛擬料面。柱體體積已在數值中解析扣除，但沒有在這份檢查用上表面挖出所有柱孔，也沒有建立地坪底面與側面。

因此不能直接將匯出檔交給只接受「封閉實體體積」的工具，期待得到相同淨體積；該檔用於檢查料面形狀、跨接、缺口與邊界。PLY 使用 double XYZ、三角面索引、共同建築座標及地坪註記；不捏造原始強度。既有輸出不覆寫。

## 實作與驗證

Qhull 建立 TIN，Boost.Geometry 處理場域幾何；結構交集由 `ColumnVolumeMask::intersectSurface` 的局部三維差集完成。C++ 測試涵蓋解析平面／斜面、凹邊界、門檻、重疊與有界結構、支點優先、缺測、小區與不覆寫匯出。數學測試不等於現場庫存精度驗證。
