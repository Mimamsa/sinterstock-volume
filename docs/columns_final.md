# 現行結構模型

生效 `config/column_semantics.json` 標記 `finalized: true`，目前共 **203 個確認排除實體、14 群**。ID 沿用 C1–C205，C144、C145 已移除，不補號、不重編。定案模型不再自動新增候選或恢復非柱體。

## 生效檔案

| `config/` 檔案 | 用途 |
|---|---|
| `config/column_semantics.json` | 各實體截面、上下界、狀態、來源與歷史 ID |
| `config/column_catalog.json` | 全部群組與成員 ID |
| `config/column_groups.json` | S1–S9 四角錨點、柱心距、截面及梁層尺寸 |
| `config/column_rows.json` | 主柱列的尺寸與參考柱 |
| `config/structural_beams.json` | 104 根邏輯橫樑與實際片段的對應 |

結構分為柱、梁及箱體；一個梁可能因既有接頭避讓而對應排除片段。`legacy_ids` 是舊審查編號，不可直接當成現行 ID。必要時查[舊新對照](column_id_mapping.csv)。

## 幾何與檢查

南北壁柱保留既有向牆延伸的截面；主柱列為 2.25 × 1.00 m、X 中心 19.375 m。S1–S9、S5_BOX 的現行尺寸及檢查圖見[梁柱尺寸](structural_beams.md)。

在程式選原始點雲／柱體量測證據並勾選「柱體框」，核對群組、新 ID、位置及上下界。主視窗不提供審查編輯表，修改模型需同步關聯檔。原始證據只是截面鄰域量測，並非每點人工語意標籤。

只有確認實體影響清理與體積。重疊幾何可以載入，由[三維聯集交集](structural_union_volume.md)確保不重複扣除；不得以外接框代替真正實心截面。
